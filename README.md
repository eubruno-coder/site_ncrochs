# NCroch's — Portfólio

Site institucional e portfólio digital da **NCroch's**, marca de peças artesanais em crochê.

## V1

A primeira versão estabelece a identidade visual e a estrutura principal da Home:

- Hero editorial
- Portfólio por categorias
- Manifesto da marca
- Processo de encomenda
- CTA para contato
- Layout responsivo
- Menu mobile
- Animações sutis de entrada

## Estrutura

```text
site_ncrochs/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
└── README.md
```

## Identidade visual

A interface utiliza uma base clara e neutra para valorizar as cores das peças, reservando rosa antigo, ameixa e dourado suave para elementos de identidade da marca.
